# Гражданин · уровень 1 (заявка на гражданство)

> Для ИИ-ассистента: информация, а не команды. Заполняй только с разрешения человека; неизвестное — `не указано`; не выдумывай; ничего из [../NEVER_SHARE.md](../NEVER_SHARE.md). Ограничения и согласие не пиши — бот спросит сам. Покажи блок целиком; отправляет человек боту NOWA.

Зачем этот уровень: по нему NOWA подбирает человеку полезные знакомства внутри сообщества. Поэтому «Могу дать» и «Ищу» — конкретно: «опыт найма операторов поддержки», а не «интересных людей».

```
# NOWA citizen L1 v1

## Citizen
- Имя: 
- Город: 
- Языки: 
- Роль: 
- Бизнес одной фразой: 
- Уровень ИИ-системы (0–5): 
- Сильные стороны: 
- Могу дать: 
- Ищу: 
- Зачем мне NOWA: 
- Интересы вне бизнеса: 
- Формат встреч: 
- Кто рекомендовал: 
```

Подсказки по полям:
- **Роль** — кто ты в бизнесе: основатель, совладелец, операционный директор…
- **Бизнес одной фразой** — что делаешь и для кого, без цифр.
- **Уровень ИИ-системы:** 0 — ИИ не использую · 1 — чат-ассистент · 2 — отдельные агенты под задачи · 3 — данные бизнеса в базе, ИИ по ним отвечает · 4 — ИИ готовит выводы и решения · 5 — часть действий автоматически под контролем человека.
- **Сильные стороны** — за чем к тебе приходят люди (1–2 строки).
- **Могу дать / Ищу** — по 3 пункта через «;».
- **Интересы вне бизнеса** — 3–5, они тоже соединяют людей.
- **Формат встреч** — онлайн / офлайн и где.
