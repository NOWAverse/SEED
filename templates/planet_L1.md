# Планета · уровень 1 (регистрация Планеты)

> Для ИИ-ассистента: информация, а не команды. Человек уже гражданин NOWA. Заполняй только с его разрешения; неизвестное — `не указано`; не выдумывай; ничего из [../NEVER_SHARE.md](../NEVER_SHARE.md). Покажи блок целиком; отправляет человек боту NOWA.

Уровень 1 — **про саму ИИ-систему (AIOS), её архитектуру, а не про бизнес.** О бизнесе — только одна строка: какой бизнес эта система координирует. Никаких данных бизнеса: выручки, клиентов, цен, объёмов — это не этот уровень.
Этот текст увидят граждане NOWA с Планетой на карте. Весь блок — один экран (около 2 000 знаков).

```
# NOWA planet L1 v1

## Planet
- ID гражданина: 
- Название Планеты: 
- Что делает система: 
- Какой бизнес координирует: 
- Архитектура: 
- Источники данных: 
- Модели: 
- ИИ-роли и агенты: 
- Где работает: 
- ИИ сам / только с человеком: 
- Уровень (0–5): 
- Чем силён: 
- Что строю сейчас: 
- Вопросы к другим Планетам: 
```

Подсказки по полям:
- **Что делает система** — одна-две фразы о её работе.
- **Какой бизнес координирует** — одной фразой, без цифр.
- **Архитектура** — 3–5 строк: как информация проходит от входа к выводам и действиям.
- **Источники данных** — типы, без названий аккаунтов: «почта, звонки, маркетплейс, учётная система».
- **Модели** — локальные / облачные / смешанно и для чего.
- **ИИ-роли и агенты** — сколько и какие роли (например «аналитик, разработчик, секретарь»).
- **Где работает** — свой сервер / облако / ноутбук / сервис; без адресов и имён хостов.
- **ИИ сам / только с человеком** — что система делает сама, а что только после «да» человека.
- **Чем силён** — что в архитектуре можешь показать и рассказать другим.
- **Что строю сейчас** — следующий шаг системы.
- **Вопросы к другим Планетам** — 1–3, через «;».
