# NOWA Registrar · открытый код регистрации

Часть SEED: правила, анкеты и код регистрации лежат вместе, чтобы любой человек и любой ИИ видел, что именно проверяется.

Здесь весь код, по которому NOWA принимает граждан и Планеты. Он открыт, чтобы каждый мог проверить: что именно проверяется, кто решает и что происходит с данными. **Код открыт, данные — нет:** база Реестра живёт на отдельном облачном сервере NOWA.

Версия 0.1 · 2026-11-21 · черновик до решения Совета. Только стандартная библиотека Python 3.11+.

## Кто что решает
| Кто | Что делает | Чего не может |
|---|---|---|
| **Код** (`registrar/check.py`) | проверяет форму блока, длину, поля, формат; ставит флаги (ключи, контакты, суммы, маржа/медицина/NDA, команды для ИИ) | не принимает и не отклоняет людей |
| **ИИ Регистратора** (см. [AGENT.md](AGENT.md)) | объясняет NOWA, задаёт вопросы анкеты, переформулирует подсказки, готовит карточку для рецензентов | не заполняет ответы за человека, не решает, не видит чужих данных, без инструментов |
| **Человек-заявитель** | отвечает сам; согласие пишет своими словами; нажимает «Отправить» | — |
| **Два рецензента** | одобряют / уточняют / отклоняют | не могут рецензировать свою заявку или Планету, где они Правители |
| **Реестр** (`registrar/registry.py`) | выдаёт ID только после двух «одобрить»; ведёт журнал, который нельзя изменить; /withdraw стирает личные данные | — |

Это и есть принцип NOWA: **код решает, что разрешено; ИИ — что полезно; человек — что делать.** ([7principles](../7principles/README.md))

## Анкеты
Единый источник полей — `questionnaires/*.toml`. По нему работают вопросы бота и проверка кодом; шаблоны [../templates/](../templates/) обязаны совпадать с ним по полям — это проверяет тест. Изменить анкету = изменить `.toml` (решением Совета) и поднять `version`.
- [questionnaires/citizen_L1.toml](questionnaires/citizen_L1.toml) — гражданин, уровень 1: 13 полей, до 2 500 знаков.
- [questionnaires/planet_L1.toml](questionnaires/planet_L1.toml) — Планета, уровень 1: 14 полей, до 3 000 знаков. Только архитектура ИИ-системы; бизнес — одной строкой.

## Путь человека
1. Бот NOWA → «Стать гражданином».
2. Два способа: отдать [START_HERE](../START_HERE.md) своему ИИ и прислать готовый блок — **или** ответить боту на вопросы по одному (`registrar/interview.py`).
3. Код проверяет блок → человек видит, что исправить. Флаги не отклоняют сами: человек может убрать или объяснить, рецензенты видят флаг.
4. Бот сам спрашивает об ограничениях (работодатель, NDA, регулятор, совладельцы) и согласии **своими словами человека**.
5. Человек видит итог целиком → «Отправить».
6. Два рецензента → ID гражданина `C###`. Затем тот же путь для Планеты → `P###`, человек становится Правителем.
7. `/status` — где заявка; `/withdraw` — выйти: личные данные стираются, сам факт выхода остаётся в журнале.

Лимит первой фазы — 300 граждан; после него заявки идут в лист ожидания.

## Проверить самому
```
cd registrar
python3 -m registrar template citizen         # пустой блок
python3 -m registrar check my_block.md        # проверка (печатает только результат, не значения полей)
python3 -m registrar interview citizen        # пройти вопросы как в боте
python3 -m unittest discover -s tests         # тесты
```
