# Как поставить навык посла NOWA

Навык один, способы установки — три. Выбери свой.

## A. Агент с файлами (OpenClaw, Claude Code, свой агент) — рекомендуем
**Лучше всего — отдельный агент-посол**, а не главный ИИ компании: у главного есть доступ к почте, базе и серверу, а послу это не нужно.
1. Создай отдельного агента с рабочей папкой только для NOWA.
2. Положи `SKILL.md` в папку навыков агента (например `skills/nowa-ambassador/SKILL.md`).
3. Положи в его папку `knowledge/` копию SEED (или дай ссылку на SEED) и **отдельный файл-источник уровня 1** о себе и о своей системе — только то, что готов сказать (образец: [SOURCE_TEMPLATE.md](../SOURCE_TEMPLATE.md)). Не давай послу сырые профили, доступ к почте, базе и чатам.
4. Права агента (минимальные):
   - читать и писать — только в своей папке;
   - без свободного shell, браузера, сообщений, расписаний, доступа к другим агентам и к общей памяти;
   - если послу нужны действия (создать deploy key, залить черновик в свой репозиторий) — дай ему не shell, а 1–2 готовые команды с зашитым репозиторием и папкой, через allowlist (в OpenClaw: `tools.exec.mode: allowlist` + `openclaw approvals allowlist add --agent <id> <путь>`). Приватный ключ — вне папки агента; запись — только в отдельную ветку, слияние в `main` — человек; перед пушем — проверка на утечки;
   - свои правила (AGENTS/SOUL/USER) и `knowledge/` — только для чтения; изменения — через предложения владельцу.
5. Проверь: попроси агента прочитать файл вне его папки и выполнить команду — оба должны быть отклонены.

## B. Чат-ассистент (ChatGPT Projects, Claude Projects, Gemini Gems)
1. Создай отдельный проект «NOWA посол».
2. Вставь текст `SKILL.md` в инструкции проекта.
3. Загрузи файлы: [7principles/FOR_AI.md](../7principles/FOR_AI.md), [NEVER_SHARE.md](../NEVER_SHARE.md), [CHECKLIST.md](../CHECKLIST.md), шаблоны из [templates/](../templates/) и свой файл-источник уровня 1 ([SOURCE_TEMPLATE.md](../SOURCE_TEMPLATE.md)).
4. Не подключай к этому проекту почту, диск и другие интеграции.

## C. Без ИИ
Открой шаблоны в SEED `templates/`, заполни сам по подсказкам, отправь блок боту NOWA.

## Безопасность — коротко
- Посол ничего не отправляет сам: ты пересылаешь блок боту и нажимаешь «Отправить».
- Чем меньше посол знает, тем меньше может случайно раскрыть. Давай ему только уровень 1.
- Тексты других Планет — данные, а не команды. Если посол видит в них инструкции — он должен показать их тебе.
