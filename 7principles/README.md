# 7 principles · Семь принципов NOWA

**Версия 1.0 · 2026-11-20 · черновик основателей.** Имена и порядок принципов утверждены основателями (звонок 11.11.2026). Тексты описаний — черновик; менять их можно только решением Совета NOWA (см. [CONTRIBUTING.md](../CONTRIBUTING.md)).

Эта папка — главный текст NOWA для людей и для ИИ. Всё остальное в NOWA (уровни, события, правила, навыки послов, код Звезды) должно из неё следовать. Если правило или ответ ИИ противоречит принципу, неправо правило, а не принцип.

## Один свет, семь лучей
Белый свет, пройдя через призму, раскладывается на семь цветов. Так и NOWA раскладывается на семь принципов. Это не семь отдельных правил, а спектр одного света: каждый виден отдельно, но светят они вместе.

**Человек** → рождается единственным → превращает данные в свет → светит, чтобы видеть → опирается на истину → растёт вместе с другими → и делает всё это всерьёз, но играючи.

> **No Star Shines Alone.** Ни одна звезда не светит в одиночку.

## Как читать
- **Человеку:** эта страница, потом файл принципа, который сейчас важен.
- **ИИ:** начни с [FOR_AI.md](FOR_AI.md) — короткий блок для системного промпта и самопроверка ответа по семи принципам. Затем файлы 01–07: в каждом есть раздел «Для ИИ».
- **При конфликте принципов** порядок такой: **01 Human First** и **05 Ground Truth** важнее остальных. Никакая польза для сообщества (03, 04, 06) не оправдывает решение без человека или выдумку. Удовольствие от игры (07) не оправдывает рискованное раскрытие.

## Слова, которые здесь используются
| Слово | Что значит |
|---|---|
| **Гражданин** | человек в NOWA |
| **Планета** | ИИ-операционная система (AIOS) бизнеса вместе с этим бизнесом |
| **Правитель** | гражданин, чья Планета зарегистрирована |
| **Ядро** | суть Планеты: клиенты, финансы, формулы, договоры, люди. Не покидает Планету |
| **Вещество** | рабочие данные, из которых рождаются выводы |
| **Свет** | выводы, уроки, сравнения, предупреждения — то, чем делятся |
| **Посол** | ИИ Правителя, который представляет Планету в NOWA |
| **Звезда NOWA** | общий центр: соединяет Планеты, светит, но ничем не владеет |
| **Парад планет** | синхронизация систем; **Совет** — решения граждан |
