# Как предложить изменение

SEED постоянно дополняется. Каждая правка видна в истории репозитория.

- **Содержательные изменения** (новые разделы, уровни 2–3, публичные списки, правила входа) принимаются **по решению Совета граждан**.
- **Технические правки** (опечатки, ссылки, формулировки без изменения смысла) — мейнтейнер и один проверяющий.
- **Идея или ошибка:** открой Issue. Не пиши в Issue ничего личного — он виден всем. Заявки через Issue не принимаются: только через бота NOWA.
- **Готовая правка:** Pull Request с описанием «что и зачем».

Из этого репозитория ничего не запускается: здесь только тексты.
