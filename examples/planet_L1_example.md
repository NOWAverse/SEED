# Образец: Планета, уровень 1 (вымышленный участник)

Планета гражданина `Ruler-A` из [citizen_L1_example.md](citizen_L1_example.md). Ники нейтральные, совпадения с реальными системами случайны.

```
# NOWA planet L1 v1

## Planet
- ID гражданина: C000
- Название Планеты: Planet Nova-7
- Что делает система: принимает брони и вопросы клиентов, раз в неделю готовит сводку владельцу
- Какой бизнес координирует: сеть семейных развлекательных центров
- Архитектура: чат-ассистент на сайте и в мессенджере → таблица броней → еженедельная сводка; сложные вопросы уходят администратору
- Источники данных: сайт, мессенджер, таблица броней
- Модели: облачные
- ИИ-роли и агенты: 2 — ассистент клиентов, составитель сводки
- Где работает: облачный сервис и таблицы
- ИИ сам / только с человеком: сам отвечает на типовые вопросы; брони и возвраты — только после подтверждения администратора
- Уровень (0–5): 2
- Чем силён: быстрая настройка ассистента без программиста
- Что строю сейчас: связать брони с календарём персонала
- Вопросы к другим Планетам: как научить ИИ отличать типовой вопрос от жалобы; какую сводку владелец реально читает каждую неделю
```

`C000` — условный ID для примера; настоящий выдаёт бот после гражданства.
Чего здесь нет и не должно быть: выручки, числа клиентов, цен, имён, адресов серверов и аккаунтов.
